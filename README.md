# 📊 Customer and Marketing Performance Analysis – AtliQ Hardware

This project analyzes the customer and marketing performance of AtliQ Hardware using Excel.
The goal is to understand revenue trends, customer contribution, market behavior, and year-over-year performance to support better data-driven decisions.


## 🔍 Project Overview
The dataset includes customer details, product information, market performance, and net sales for multiple years.
I performed data cleaning, transformation, KPI creation, and built an Excel dashboard to highlight key insights.

This analysis helps identify:
- Top contributing customers
- Underperforming markets
- New products launched in 2021
- Revenue growth trends
- Customer segmentation



## 🧹 Data Cleaning & Preparation
- Removed duplicates and inconsistent values
- Standardized formats and data types
- Created calculated fields (YoY growth %, contribution %)
- Structured tables using Power Query
- Prepared data for pivot-based reporting


## 📈 Analysis & Insights
Key findings from the dashboard:

- A few major customers contribute most of the company’s revenue
- Several new 2021 products show strong potential
- Some markets show declining sales and require focused strategy
- Customer segmentation identifies high- and low-value clients
- Year-over-year analysis highlights clear growth patterns



## 📊 Dashboard Features
The Excel dashboard includes:
- Customer performance ranking
- Market-wise net sales comparison
- Product contribution charts
- YoY growth visuals
- KPI cards (Net Sales, Contribution %, New Customers, etc.)
